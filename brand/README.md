# WasiatHub Brand Assets

## Logo Files

| File | Use |
|---|---|
| `logo.svg` | Full logo — icon + wordmark. Use for website, Canva, email headers, presentations |
| `logo-mark.svg` | Icon only — for Facebook/TikTok profile picture, favicon, app icon, small spaces |
| `logo-white.svg` | White version — for dark backgrounds (social posts, hero sections, printed on dark material) |

## Brand Colours

| Name | Hex | Use |
|---|---|---|
| Emerald (primary) | `#10b981` | Buttons, highlights, "Hub" in wordmark, accents |
| Dark (secondary) | `#0f172a` | Backgrounds, "Wasiat" in wordmark, body text on light |
| White | `#ffffff` | Text on dark backgrounds |
| Light emerald | `#6ee7b7` | Light accent, white logo variant |

## Usage Notes

- Minimum size: 120px wide for full logo, 32px for icon mark
- Always maintain clear space around the logo (at least the height of the "W" icon on all sides)
- Do not stretch, recolour or add effects to the logo
- SVG files scale to any size without quality loss — use SVG wherever possible

## Web URLs (live on wasiathub.my)

- Full logo: `https://wasiathub.my/logo.svg`
- Icon mark: `https://wasiathub.my/logo-mark.svg`
- White version: `https://wasiathub.my/logo-white.svg`

## For Social Media

- **Facebook page profile picture** → use `logo-mark.svg` (displayed as circle)
- **TikTok profile picture** → use `logo-mark.svg`
- **Canva header/post** → import `logo-white.svg` for dark backgrounds, `logo.svg` for light
